# 私人网盘

Windows 服务端把文件保存在 `E:\PrivateNAS`。iPhone 客户端支持账号登录、文件夹浏览、当前目录搜索、文件上传、相册批量上传、下载、预览、分享、新建目录及删除。单个上传文件上限为 20 GiB。同名文件上传会被拒绝。

## Windows

桌面的「私人网盘.exe」内嵌启动脚本、服务端和图标。只复制这一个 EXE 就能在另一台 64 位 Windows 使用。服务启动、首次账号设置和状态提示都在同一个窗口。关闭窗口后，服务继续在后台运行。已有本机配置会直接复用。电脑未装 Node.js 22 或更新版本时，首次运行会联网下载便携运行时。需要重新生成 EXE 时，在项目根目录运行 `./server/Build-DesktopLauncher.ps1`。

在 Windows 程序的「网盘目录」旁点「选择文件夹」，可将已有目录设为网盘根目录。「打开网盘文件夹」会打开当前选定的目录。切换后，手机需重新登录才能访问新目录。原目录文件会留在原位置。

也可以只复制 `PrivateNAS.bat` 到另一台 64 位 Windows。BAT 内嵌 Windows 启动脚本和服务端源码。已有 Node.js 22 或更新版本时直接使用，否则首次启动会从 Node.js 官方站点下载便携运行时并检查 SHA‑256。首次运行会引导设置账号，并在本机生成证书，随后显示局域网地址和证书指纹。文件默认放在 `E:\PrivateNAS`，没有 E 盘时使用 `%USERPROFILE%\PrivateNAS-Files`。运行 BAT 时请保持窗口打开。

如果另一台设备无法连接，在管理员终端运行 `.\私人网盘.exe --firewall`（BAT 版使用 `.\PrivateNAS.bat --firewall`），允许专用网络的本地子网访问 TCP 8787。然后在 iPhone App 里通过「新增服务器」填写控制台显示的地址和指纹。修改服务端或便携启动脚本后，运行对应的构建脚本重新生成 EXE 或 BAT。

现有电脑可使用已找到的 Node.js 运行时。其他电脑需要 Node.js 22 或更新版本，并用 PowerShell 7 生成证书。以下命令在项目根目录执行。

```powershell
./server/New-TlsIdentity.ps1 -ServerName 192.168.0.111
./server/Set-Owner.ps1 -Username mynas
./server/Start-NAS.ps1
```

证书只需生成一次。保存脚本输出的 64 位十六进制 SHA-256 指纹，并从可信渠道在 iPhone 上录入。证书私钥及账号哈希存放于 `%LOCALAPPDATA%\PrivateNAS`。再次运行 `Set-Owner.ps1` 可更换账号或密码，旧登录立即失效。用户名使用 1–32 个字符，可用中文、字母、数字、下划线或连字符。新设密码使用 8–12 个字符，由 Windows 终端隐藏输入。默认只有一个网盘所有者账号。

在管理员 PowerShell 中运行 `./server/Enable-Firewall.ps1`，放行专用网络上的 TCP 8787。如果 Node.js 未加入 PATH，给上述账号、启动及防火墙脚本传入 `-NodePath 'C:\实际位置\node.exe'`。前台运行时请保持窗口打开。电脑需要联网且处于唤醒状态。

## iPhone

用 Mac 上的 Xcode 打开 `ios/PrivateNAS.xcodeproj`，在目标的 **Signing & Capabilities** 中选择自己的签名团队并运行到 iOS 17 或更新版本的 iPhone。如果签名提示 Bundle Identifier 冲突，可换成自己的标识。

先在 iPhone 上连接 Tailscale，再在登录首页点「家庭网盘」。默认地址是 `https://desktop-evd50fu.tail5100bc.ts.net`，由 iOS 验证 HTTPS 证书。首次只需输入已设置的网盘密码。之后密码保存在该 iPhone 的钥匙串中，点服务器即可连接。已有家庭网盘配置会自动切换到此地址并复用钥匙串密码。长按服务器可编辑配置或更新密码。

通过「新增服务器」填写服务器名称、HTTPS 地址、用户名和密码。使用受系统信任的证书时可留空指纹。使用自签名证书时，App 按指纹校验服务器身份，同一张证书可以用于局域网和公网两个地址。更换证书后从 Windows 重新确认指纹。

进入要保存照片的文件夹，点右上角「上传」→「上传照片和视频」，一次最多选择 30 项。App 按顺序上传，并显示成功数量。相册文件名会加短前缀，以区分相册里的同名照片。

文件列表会为可见的照片、PDF 和支持的文档自动显示缩略图。超过 12 MiB 或暂时无法生成缩略图的项目显示文件类型图标。点文件或照片直接打开 iOS Quick Look 预览，关闭后清理临时文件。右滑或长按文件，选择「下载」，在系统文件夹选择器确认保存位置后才开始下载。同名文件会保留，App 会提示选择其他位置。

左滑或长按文件和文件夹，选择「删除」并确认。删除文件夹会永久删除其中的文件和子文件夹。

长按文件或文件夹可选「复制」「剪切」或「重命名」。复制或剪切后，打开目标文件夹，在底部点「粘贴到这里」或「移动到这里」。如果目标位置已有同名项目，App 会提示并保留两个位置的原文件。剪贴板仅用于 App 内的网盘项目。

## 公网直连

1. 在路由器管理页看 WAN IPv4，并和家庭网络对外显示的公网 IPv4 比较。若 WAN 处于运营商级 NAT，需向运营商申请公网 IPv4，或使用可入站的公网 IPv6。也可以部署自管公网中继，本项目当前实现的是直连。
2. 在路由器为 Windows 电脑保留 `192.168.0.111`，添加 TCP 8787 到该电脑 TCP 8787 的端口转发。仅转发网盘的 HTTPS 端口。IPv6 直连时将服务端环境变量 `NAS_BIND` 设为 `::`，并在路由器 IPv6 防火墙放行该端口。
   家中有两层路由时，上游路由器也需要把同一端口转发到下游路由器的 WAN 地址。
3. 在 iPhone 上关 Wi‑Fi，用移动数据连接 `https://公网IPv4:8787`，或填指向公网地址的域名。IPv6 字面地址写成 `https://[IPv6地址]:8787`。使用同一个网盘账号和证书指纹。

IPv4 变化后，在 App 里更新地址，或自行维护域名的 DNS 记录。直连需要 Windows 服务器进程保持运行。
